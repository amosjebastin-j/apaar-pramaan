Prototype demo guide

For evaluators and team members. This page is part of the prototype and is not part of the production portal.

1 · Institution

Login inst001 / inst123

  1. Upload Student Data → Download sample file → upload it.
  2. Filter the result: Rejected (not saved), Warnings, Accepted.
  3. Upload the same file again → rows show as Records updated.
  4. Add / Update Student → click a demo ID → Fetch from registry → Save.
  5. Students & Certificates → Generate certificate (APAAR ID + Student ID + QR).
Institution login

2 · AICTE

Login aicte / aicte123

  1. Overview: utilisation chart, excess-enrolment alerts and live activity (refresh after step 1).
  2. Risk & Anomalies → click an institution ID.
  3. Duplicate Enrolment, then Student Record Search.
  4. Audit & Reports → printable report, CSV, audit chain.
AICTE login

3 · Verifier

Login employer / verify123

  1. Click an enrolled demo ID → Request consent.
  2. Enter the OTP shown in the simulated student phone.
  3. Open the public verification link → AUTHENTIC.
  4. Change one character of the token → INVALID / TAMPERED.
